# Tanzania Cutover

**Type:** runbook

1. Verify catalog hashes and approved Tanzania dataset versions.
2. Run output simulation and parity validation against the approved endpoint behavior.
3. Confirm secure artifact paths, certificate validity, and credential access.
4. Verify online, offline, retry, duplicate, credit-note, and recovery scenarios.
5. Confirm cloud endpoint monitoring and rollback routing.
6. Obtain fiscal, operational, and organizational sign-off.
7. Enable the cutover in a controlled window and monitor document identity, queue depth, failures, and response codes.
8. Roll back when acceptance thresholds are breached; do not repair identity mismatches by creating replacement fiscal documents without approved procedure.
